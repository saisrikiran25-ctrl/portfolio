🚀 Deployment & Preview Guide

Get your portfolio live in under 10 minutes — completely free.

Option A — VS Code Live Server (Recommended)

  1. Download all 3 generated files (use the Download All Files button above)
  2. Create a folder, e.g. my-portfolio/, and place all files inside
  3. Open the folder in VS Code
  4. Install the Live Server extension by Ritwick Dey (Extensions panel → search "Live Server")
  5. Right-click index.html in the file explorer → "Open with Live Server"
  6. Your portfolio opens instantly at http://127.0.0.1:5500 🎉

Option B — Browser-Based (Instant, No Install)

  1. Go to CodePen.io
  2. Create a new pen and paste the index.html content into the HTML panel
  3. Paste styles.css into the CSS panel
  4. Paste app.js into the JS panel
  5. See your live portfolio instantly — no account required for basic preview

Option C — Python HTTP Server

  1. Save all files to a folder
  2. Open terminal in that folder
  3. Run: python -m http.server 8000
  4. Open http://localhost:8000 in your browser

GitHub Pages — Free Hosting (yourname.github.io)

  1. Create a free account at github.com
  2. Create a new repository named yourname.github.io (replace "yourname" with your GitHub username)
  3. Download your 3 portfolio files using the button above
  4. Upload all files to your repository via the GitHub web interface (drag & drop)
  5. Go to repository Settings → Pages → Source → Deploy from branch → main
  6. Wait 2-3 minutes — your portfolio is live at https://yourname.github.io 🎉
Pro Tip: Use the GitHub CLI: git init && git add . && git commit -m "Launch portfolio" && git push

Netlify — Drag & Drop Deployment (Easiest)

  1. Go to netlify.com — sign up free
  2. Download all portfolio files and put them in a folder
  3. From the Netlify dashboard, find the "Drag and drop your site folder here" area
  4. Drag your portfolio folder directly onto the Netlify dashboard
  5. Netlify deploys in ~10 seconds and gives you a URL like random-name.netlify.app
  6. Optionally, go to Site Settings → Change site name to customize your URL
  7. Connect a custom domain from Domain Management anytime

Vercel — GitHub-Integrated Deployment

  1. Push your portfolio files to a GitHub repository (see GitHub steps above)
  2. Go to vercel.com and sign up with your GitHub account
  3. Click "New Project" → Import your portfolio repository
  4. Vercel auto-detects it's a static site — click Deploy
  5. Your portfolio is live at yourproject.vercel.app in under 60 seconds
  6. Every future push to GitHub automatically redeploys — instant CD pipeline 🔄
